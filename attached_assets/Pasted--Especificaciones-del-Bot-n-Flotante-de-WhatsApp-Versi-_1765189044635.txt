 Especificaciones del Botón Flotante de WhatsApp (Versión Desktop)
1. Posicionamiento
Posición: fixed (fijo en pantalla, no se mueve con el scroll)
Ubicación: Esquina inferior derecha
Distancia desde abajo: 30px
Distancia desde la derecha: 30px
Z-index: 1000 (para que esté por encima de todo el contenido)
2. Dimensiones
Ancho: 75px
Alto: 75px
Padding interno: 15px
Forma: Círculo perfecto (border-radius: 50%)
3. Colores
Color de fondo: #25D366 (verde oficial de WhatsApp)
Color del icono: #FFFFFF (blanco)
4. Sombra
Normal: box-shadow: 0 4px 15px rgba(0, 0, 0, 0.25)
Al pasar el mouse: box-shadow: 0 6px 15px rgba(0, 0, 0, 0.25)
5. Animaciones
Efecto Pulse (pulsación continua)
@keyframes pulse {

    box-shadow: 0 0 0 15px rgba(37, 211, 102, 0);
  }
  100% {
    box-shadow: 0 0 0 0 rgba(37, 211, 102, 0);

Duración: 2 segundos
Repetición: infinite (infinita)
Efecto Hover (al pasar el mouse)
Transformación: scale(1.1) (crece un 10%)
Transición: transform 0.3s ease, box-shadow 0.3s ease

8. Funcionalidad del Click
Al hacer click, abre WhatsApp con un mensaje predefinido:

const phoneNumber = "TU_NUMERO_AQUI"; // Sin + ni espacios
const message = encodeURIComponent("Tu mensaje predefinido aquí");
const whatsappUrl = `https://wa.me/${phoneNumber}?text=${message}`;
window.open(whatsappUrl, '_blank');

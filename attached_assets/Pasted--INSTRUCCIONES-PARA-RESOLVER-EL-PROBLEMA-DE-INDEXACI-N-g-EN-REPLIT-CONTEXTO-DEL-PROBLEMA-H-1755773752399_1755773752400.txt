?? INSTRUCCIONES PARA RESOLVER EL PROBLEMA DE INDEXACIÓN ?_g= EN REPLIT
?? CONTEXTO DEL PROBLEMA
He analizado tu problema de los parámetros ?_g= que están generando miles de URLs duplicadas en Google Search Console. Como experto que ha resuelto este mismo problema en otro proyecto exitoso (Veritas Medical Centers), te voy a dar la solución definitiva.

? DIAGNÓSTICO CONFIRMADO
El problema está 100% confirmado que proviene del script:

<script type="text/javascript" src="https://replit.com/public/js/replit-dev-banner.js" async></script>
Este script de Replit está inyectando automáticamente los parámetros ?_g= + números únicos para tracking interno de la plataforma, no es algo que el usuario haya implementado.

?? SOLUCIÓN PROBADA (IMPLEMENTADA EXITOSAMENTE EN PROYECTO VERITAS)
PASO 1: IDENTIFICAR Y REMOVER EL SCRIPT PROBLEMÁTICO
Busca en el HTML principal del proyecto el script mencionado arriba
Remuévelo completamente - No es esencial para el funcionamiento de la aplicación
Verificar que no esté en otros archivos HTML o componentes
PASO 2: IMPLEMENTAR PROTECCIÓN SEO PREVENTIVA
A. Crear/actualizar robots.txt:

User-agent: *
# Bloquear URLs con parámetros de tracking de Replit
Disallow: /*?_g=
# Bloquear directorios de backend
Disallow: /api/
Disallow: /server/
# Indicar sitemap
Sitemap: https://tudominio.com/sitemap.xml
B. Implementar canonical URLs en cada página:
Asegúrate de que cada página tenga:

<link rel="canonical" href="https://tudominio.com/pagina-actual" />
PASO 3: CONFIGURAR PLUGINS DE REPLIT CORRECTAMENTE
Solo mantener estos plugins de Replit (son seguros):

@replit/vite-plugin-cartographer - Solo en desarrollo
@replit/vite-plugin-runtime-error-modal - Solo en desarrollo
Configuración segura en vite.config.ts:

...(process.env.NODE_ENV !== "production" &&
process.env.REPL_ID !== undefined
  ? [
      await import("@replit/vite-plugin-cartographer").then((m) =>
        m.cartographer(),
      ),
    ]
  : []),
??? RESPUESTA A: ¿AFECTA REMOVER EL SCRIPT?
NO, remover el script replit-dev-banner.js NO afecta negativamente:

Funcionalidad de la aplicación web
Performance de la aplicación

Funciones esenciales de Replit

? LO ÚNICO QUE SE PIERDE:

El banner de desarrollo que aparece cuando alguien visita tu app fuera de Replit
